# متجر عالم الصغار

## التشغيل المحلي

يتطلب Node.js `24.9.0` أو أحدث. أنشئ `.env` من النموذج إذا لم يكن موجوداً، ثم شغّل:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
npm start
```

افتح `http://localhost:3000`. يجب استخدام هذا العنوان بدلاً من Live Server، لأن واجهة المتجر تعتمد على واجهات الخادم وقاعدة SQLite.

تُنشأ قاعدة البيانات تلقائياً في `data/store.sqlite`، وتُضاف المنتجات الأولية عند أول تشغيل. أسعار المنتجات وخيارات الألوان والمقاسات والتوصيل تُتحقق في الخادم عند تسجيل الطلب.

## الدفع الإلكتروني وإدارة المنتجات

- الدفع عند الاستلام متاح محلياً دون إعداد إضافي.
- الدفع عبر Chargily معطّل حتى ضبط `CHARGILY_MODE=test` و`CHARGILY_SECRET_KEY` في `.env`. لا تضع المفاتيح السرية في ملفات الواجهة أو تشاركها.
- يتطلب وضع الإنتاج `CHARGILY_MODE=live` ورابطاً عاماً آمناً عبر HTTPS في `PUBLIC_URL`، مع تهيئة webhook لدى مزود الدفع.
- عيّن `ADMIN_API_KEY` في `.env` لإدارة المنتجات من واجهة المتجر. أدخل المفتاح في لوحة الإدارة؛ لا تحفظه في جهاز عام.
- لا تُخزّن بيانات البطاقات في المتجر. حالة الدفع تُعتمد من تحقق الخادم عبر Chargily أو إشعار webhook موقع.
